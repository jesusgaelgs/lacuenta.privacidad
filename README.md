# Política de Privacidad de "La Cuenta"

**Última actualización: 26 de mayo de 2026**

Esta Política de Privacidad describe cómo la aplicación móvil "La Cuenta" (en adelante, "la Aplicación") recopila, utiliza y protege su información.

## 1. Información que recopilamos

### 1.1. Uso de la Cámara
La Aplicación solicita acceso a la cámara del dispositivo exclusivamente para el escaneo de códigos de barras (SKU) mediante tecnología de procesamiento local. Las imágenes capturadas no se graban, no se almacenan en el dispositivo ni se transmiten a servidores externos. El procesamiento se realiza en tiempo real dentro del propio dispositivo.

### 1.2. Datos de Inventario y Ventas
La Aplicación permite al usuario registrar productos (nombres, códigos, precios, inventario) y transacciones de ventas. Estos datos se almacenan localmente en el dispositivo utilizando una base de datos interna.

### 1.3. Sincronización en la Nube (Copias de seguridad)
La Aplicación cuenta con una función de respaldo que transmite los datos de inventario, ventas y registros de auditoría a una base de datos segura gestionada por el usuario (mediante el servicio Supabase). Estos datos no se comparten con terceros ni se utilizan con fines publicitarios.

## 2. Permisos del Dispositivo
Para funcionar correctamente, la Aplicación requiere los siguientes permisos:
* **Cámara:** Para escanear códigos de barras de los productos.
* **Vibración:** Para emitir retroalimentación táctil (haptic feedback) al confirmar el escaneo exitoso de un producto.
* **Internet:** Para permitir al usuario exportar sus datos de respaldo hacia su servidor en la nube.

## 3. Retención y Eliminación de Datos
Los datos generados por la Aplicación pertenecen exclusivamente al usuario. El usuario puede eliminar toda su información desinstalando la Aplicación y borrando los registros en su servidor de base de datos vinculado.

## 4. Cambios en esta Política
Nos reservamos el derecho de actualizar esta Política de Privacidad en cualquier momento. Se recomienda revisar esta página periódicamente para conocer cualquier cambio.
