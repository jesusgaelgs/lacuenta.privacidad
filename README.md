
Política de Privacidad de La Cuenta - Punto de Venta

Esta política de privacidad describe cómo La Cuenta - Punto de Venta recopila, utiliza y protege la información que proporcionas al utilizar nuestra aplicación móvil.

1. Información que recopilamos
Nuestra aplicación está diseñada para minimizar la recopilación de datos personales. Recopilamos la siguiente información:

Información de la cuenta: Para utilizar las funciones de sincronización en la nube, requerimos que crees una cuenta. Para ello, recopilamos tu dirección de correo electrónico.

Datos del negocio: La aplicación almacena la información que ingresas sobre tu negocio, como tu inventario de productos (nombres, precios, descripciones), el registro de tus ventas y los clientes (si decides registrar esa información).

2. Cómo utilizamos tu información
Utilizamos la información recopilada exclusivamente para proporcionar y mejorar los servicios de la aplicación:

Autenticación: Tu correo electrónico se utiliza para identificarte como usuario válido y permitir el acceso seguro a tu cuenta mediante los servicios de Supabase.

Almacenamiento de datos: Los datos de tu negocio (inventario, ventas) se almacenan de forma segura en la nube para que puedas acceder a ellos desde cualquier dispositivo vinculado a tu cuenta.

3. Protección de tus datos
Nos tomamos muy en serio la seguridad de tu información.

Seguridad de nivel de fila (RLS): Utilizamos políticas de seguridad estrictas en nuestra base de datos (Supabase) para asegurar que los datos de tu negocio (productos, ventas) estén completamente aislados. Esto significa que ningún otro usuario de la aplicación puede acceder, ver o modificar tu información.

Tus datos son tuyos: No vendemos, alquilamos ni compartimos la información de tu negocio ni tu correo electrónico con terceros para fines de marketing.
